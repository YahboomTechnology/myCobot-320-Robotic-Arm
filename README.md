# Introduction
myCobot 320 is a programmable 7-axis robotic arm that utilizes M5Stack-Basic, ESP32-Pico, and M5Stack-Atom multi-core collaborative control. It support various programming environments such as myBlockly visual programming, Python programming and the ROS development environment. This versatility enables it to meet different needs and programming levels of users, offering vast possibilities for innovation and experimentation. With a payload capacity of up to 1kg, a working radius of up to 350mm, and positioning accuracy within ±0.5mm. myCobot 320 is an incredibly creative development platform for makers and researchers.
# Features
* User-Centric Programming:

Tailored for user-driven programming, supporting various environments: myBlockly visual programming software, Python, C++, C#, JavaScript and ROS.

* Multi-Core Collaborative Control:

Combining M5Stack-Basic, ESP32-Pico, and M5Stack-Atom, it features an efficient multi-core collaborative control system that enhances its processing capabilities and flexibility.

* Professional Hardware Configuration:

Equipped with a 5x5 LED matrix, a 2-inch display screen, 12PCS industrialized 24V I/O electrical interfaces, and supports the installation of actuators at its end (such as adaptive grippers).

* High-performance:

Payload up to 1kg, offering a 350mm working radius, and achieving ±0.5mm positioning accuracy. Supports APP remote control(Just for Android) and ROS simulation control.
